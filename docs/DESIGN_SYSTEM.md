# 设计系统

## 当前视觉方向

融入科技风格，有想象力。首页第一阶段应围绕“今日命理场”建立产品气质：现代、克制、有推演感，但不依赖大段文字说明。

## 主题

当前主题键值：

- `day`
- `cloud`
- `night`

主题状态通过 `src/lib/theme.tsx` 持久化到 `localStorage`。

## 字体

- 展示/衬线强调字体：`Noto Serif SC`。
- 界面文字：`Inter`。
- 字体由 `index.html` 从 Google Fonts 加载。

## 重构交互原则

- 先通过视觉结构表达产品，再补充必要说明文字。
- 用户应按意图进入，而不是先理解工具分类术语。
- 首页顺序以 `docs/homepage-function-map.md` 为准：今日命理场、意图推荐区、回访与每日使用、结果可信度展示、更多探索、页脚。
- 第一屏必须优先呈现品牌定位、今日状态、五类问题入口和每日轻量入口。
- 意图推荐区每次强调 1 个主工具和 2 个备选工具，避免恢复为工具卡片海。
- 可信度展示应优先表现依据、出处、图解和术语关系，而不是做成普通资料库列表。
- 动效必须服务于状态变化、反馈或情绪聚焦。
- 避免将所有界面都做成卡片。卡片用于重复项目、工具、弹窗和需要明确边界的结果。
- 按钮文案保持简短，并明确对应动作。
- 主要控件保留至少 44px 的触控目标。
- 引入有意义的动效时，同时支持减少动态效果的系统偏好。

## 当前组件类型

- 顶部导航与移动端菜单。
- 主题切换器。
- 语言切换器。
- 登录弹窗。
- 工具卡片与实用功能卡片。
- 出生信息表单。
- 分段控制器。
- 标签与徽章。
- 结果面板。
- 会员锁定的深度解读面板。
- 知识图解。
- 分享卡片类小游戏界面。

## 重构方向

下一轮设计应从已确认的首页结构中提炼一套更小的第一阶段 UI 系统，不平均打磨当前所有页面。首页设计稿或页面方案通过后，再进入 `src/pages/HomePage.tsx` 实施。
