# 股市基础知识框架 v1

更新日期：2026-07-25

状态：一级界面内容底稿

适用范围：面向中国内地普通投资者的入门教育，不构成投资建议

## 1. 内容目标

一级界面不负责把用户训练成交易员，也不承诺帮助用户预测涨跌。它只完成三个认知任务：

1. 让用户知道股票、指数、行业、公司和市场价格分别是什么。
2. 让用户能读懂一张基础行情图，不把单根 K 线或单个指标当作结论。
3. 让用户学会用“问题—证据—反证—失效条件—复盘”组织研究。

完成首页阅读后，用户至少应能回答：

- 我正在看的是公司、指数、行业，还是某种交易产品？
- 当前图表展示的是哪个周期，价格与成交量分别表达什么？
- 支持一个判断的证据是什么，什么情况会推翻它？

## 2. 六组一级知识

### 2.1 市场与股票

必须讲清：

- 股票代表上市公司的一部分所有权，不是固定收益凭证。
- 一级市场负责发行，二级市场负责已发行证券的交易。
- 交易所、证券公司、上市公司、投资者与监管机构的角色不同。
- 指数用于描述一组证券的整体表现，不等于其中每一只股票都同涨同跌。
- 行业、主题和概念是观察市场的分类方式，口径可能不同。

首页建议文案：

> 股票是公司的所有权凭证，价格是市场在特定时点形成的交易结果。先分清“公司发生了什么”和“价格正在发生什么”。

### 2.2 价格、K 线与成交量

必须讲清：

- 一根 K 线通常包含开盘价、最高价、最低价和收盘价。
- 分时、日线、周线等周期观察的是不同时间尺度，同一标的在不同周期可能呈现不同结构。
- 成交量描述成交活跃程度，不能单独证明后续上涨或下跌。
- 均线、支撑、压力、缺口等属于观察工具，不是必然规律。
- 除权、除息、复权方式会影响历史价格图的连续性，比较前应确认口径。

首页建议文案：

> 图表记录的是已经发生的价格与成交。周期决定你看见的结构，成交量提供参与程度，但任何单一形态都不能替代证据。

### 2.3 公司基本面

必须讲清：

- 收入反映业务规模，利润反映会计口径下的经营结果，经营现金流反映现金流入流出；三者不能互相替代。
- 资产负债表用于理解资产、负债与所有者权益。
- 年报、半年报、季报、临时公告和交易所问询是重要公开信息来源。
- 增长需要同时观察可持续性、利润质量、现金流、负债与股本变化。
- 公司质量与股票短期价格表现不是同一个问题。

首页建议文案：

> 看公司不只看利润增长。收入质量、现金流、负债、股本变化与公开披露要放在一起理解。

### 2.4 估值与回报

必须讲清：

- 市值是市场价格乘以股本规模，不等于企业的账面资产或可分配现金。
- 市盈率、市净率、股息率等指标各有适用条件，不能跨行业机械比较。
- 低估值不自动代表低风险，高增长也不自动代表高回报。
- 投资回报可能来自价格变化、分红等，必须同时考虑时间、成本和风险。
- 估值是对未来假设的表达，不是一个确定答案。

首页建议文案：

> 估值不是给股票贴一个“便宜或昂贵”的永久标签，而是把价格、业务质量和未来假设放进同一套比较框架。

### 2.5 交易规则与风险

必须讲清：

- 不同交易所、板块、证券品种和业务的交易时间、申报、涨跌幅、适当性与结算规则可能不同。
- 规则内容必须链接到交易所或监管机构的现行版本，并显示最近核对日期。
- 市场风险、公司经营风险、流动性风险、政策与规则风险、信息风险都可能造成损失。
- 杠杆、融资融券、衍生品和场外配资会放大风险，不属于一级界面的入门操作引导。
- 任何教学示例都不能被包装成荐股、收益承诺或现实交易指令。

首页建议文案：

> 先知道自己交易的是什么、规则是什么、可能损失多少，再讨论机会。规则会更新，始终以交易所和监管机构的现行文件为准。

### 2.6 研究与复盘

必须讲清：

- 研究从可验证的问题开始，而不是从“会涨还是会跌”的单句预测开始。
- 一个研究命题至少包含支持证据、反证、失效条件和复查时间。
- 事实、数据、管理层表述、媒体报道和个人解释需要分层标注。
- 新证据出现后，应允许原判断被修改或推翻。
- 复盘评价的是研究过程与风险控制，不只评价最后盈亏。

首页建议文案：

> 好判断不是永远正确，而是知道自己依据什么、什么情况会错，以及何时重新检查。

## 3. 首页最小术语表

| 术语 | 一级解释 |
| --- | --- |
| 股票 | 代表上市公司部分所有权的证券 |
| 指数 | 按既定规则反映一组证券整体表现的指标 |
| K 线 | 在一个时间周期内记录开盘、最高、最低和收盘价格 |
| 成交量 | 一段时间内实际成交的数量或金额 |
| 市值 | 市场价格与股本规模共同形成的市场价值指标 |
| 市盈率 | 价格或市值相对盈利的估值指标，亏损公司等场景下需谨慎解释 |
| 分红 | 公司按规定向股东分配利润的方式之一 |
| 波动 | 价格随时间变化的幅度，不等同于永久损失但会带来风险 |
| 流动性 | 资产在合理成本下完成买卖的难易程度 |
| 失效条件 | 预先定义、出现后需要重新评估研究命题的事实或阈值 |

一级界面只展示这组最小术语；完整术语库属于后续二级内容。

## 4. 首页要纠正的常见误区

| 误区 | 一级界面纠正方式 |
| --- | --- |
| 一根大阳线代表后面还会涨 | 提示单一形态只能描述已发生的价格，需结合周期、成交、事件与反证 |
| AI 能直接预测涨跌 | 将 AI 定位为整理信息和辅助提问的工具，结论必须附来源、时间和不确定性 |
| 公司好就等于股票一定涨 | 分开呈现公司质量、价格、估值和时间尺度 |
| 低市盈率一定便宜 | 提示盈利周期、行业差异、一次性损益和未来预期 |
| 盈利就说明研究正确 | 复盘同时检查假设、证据质量、风险暴露和执行纪律 |
| 群聊或“小道消息”可以代替公告 | 默认优先公司公告、交易所与监管机构信息 |

## 5. 内容来源与更新机制

### 5.1 来源优先级

1. 中国证监会及其派出机构。
2. 上海、深圳、北京证券交易所及其投资者教育平台。
3. 上市公司在法定信息披露渠道发布的公告和定期报告。
4. 依法公开、可追溯的宏观与行业数据。
5. 媒体和第三方研究只能作为补充，并标明来源、日期和口径。

### 5.2 规则型内容

- 页面显示“最近核对：YYYY-MM-DD”。
- 交易时间、涨跌幅、适当性、申报与结算等内容不得从模型记忆直接生成。
- 若不能确认现行规则，只展示原则性说明并链接官方来源。
- 不同市场规则不得混写成一套“统一规则”。

### 5.3 示例数据

- 优先使用获得授权的延时数据或明确标注日期的历史数据。
- 不伪造实时行情，不把历史快照标为 LIVE。
- 示例标的必须标注“教学示例，不构成推荐”；首版优先使用宽基指数或去标识化教学案例。
- 价格、成交量、公告和财务数据应保留时间戳与数据来源。

## 6. 一级界面安全文案

固定短提示：

> 本页面用于证券基础知识与研究方法教育，不提供荐股、代客交易、收益承诺或个性化投资建议。市场有风险，决策前请核对官方规则与公开信息，并结合自身风险承受能力。

AI 相关固定提示：

> AI 只能辅助整理公开信息、提出问题和检查证据，可能遗漏或理解错误；重要事实需回到原始来源核验。
